## Search ownership

Preserve the `google-site-verification` meta tag in the homepage when editing or rebuilding it. Google uses that public tag to verify the official site for Search Console. It is an ownership marker, not an analytics or tracking script; removing it can interrupt verification. Keep the canonical URLs and four-page sitemap aligned with the published GitHub Pages project path.
