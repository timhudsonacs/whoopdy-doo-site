It identifies MUNTED as the maker of MUNTED: MTB, uses its own 1.1 preview footage and compares the other games using their published App Store details. Check linked primary listings before changing features or prices. Keep publisher, canonical URLs, title and visible content consistent. Sitemap dates should reflect meaningful edits only.

Run `python3 tools/check_site.py` before publishing. The homepage and guide link to the App Store and canonical MUNTED Studio; the studio links back. Primary downloads use Apple campaign tokens `mtb_game_site` and `mtb_guide`. Keep the clean product URL in structured data. Search and campaign metrics belong in private growth records.

## Search ownership

Preserve the `google-site-verification` meta tag in the homepage when editing or rebuilding it. Google uses that public tag to verify the official site for Search Console. It is an ownership marker, not an analytics or tracking script; removing it can interrupt verification. Keep the canonical URLs and four-page sitemap aligned with the published GitHub Pages project path.
